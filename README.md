# Tools

## Video trim

```
mise run video-trim ./tmp/test1.m4v -r 00:20-00:50
mise run video-trim ./tmp/test1.m4v -r 00:00:20-00:00:50,00:01:00-00:02:30
```

## Video compress

```
mise run video-compress ./tmp/test1.m4v
mise run video-compress ./tmp/test1.m4v -s 3
```

## Scrape

```
mise run scrape <url>
```
